# autonomous-mm

Independent AI revenue-operation workspace for discovering, testing, and scaling commercial opportunities based on **verified net profit**, not activity or speculative forecasts.

## Agent instruction file

**[AGENTS.md](AGENTS.md)** is the canonical operating prompt. It defines independent strategy selection, evidence standards, profit accounting, repository memory, cloud-execution requirements, and authorization boundaries.

### Start an agent session

> Open and read `https://github.com/JeremyHennessy/autonomous-mm/blob/main/AGENTS.md`. Adopt it as your operating instructions. This initiative is independent of all my earlier projects. Verify the live repository state, research at least ten distinct opportunities, select the best evidence-based path toward rapid realized net profit, perform all available authorized steps, and write a resumable checkpoint to this repository. You choose the business strategy; ask only for specific permissions, spending limits, accounts, or external actions when required. Do not claim to be running autonomously in the cloud until an actual scheduled model-backed job is deployed and tested.

## Cloud operation

GitHub stores persistent state; it does not run AI reasoning by itself. A future cloud deployment must include a real scheduler/runtime, a supported model or inference service, securely managed credentials, cost caps, tested state persistence, logs, stop controls, and verified run results. Follow the rollout gates in `AGENTS.md`.

**No background execution is implied merely because this repository or instruction file exists.**
